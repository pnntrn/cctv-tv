# Code of conduct / แนวทางการร่วมงาน

Be respectful, specific and constructive. Welcome people with different backgrounds and levels of experience. Discuss ideas and evidence without personal attacks. Harassment, threats, discriminatory abuse, sexual harassment, publishing private information and deliberate disruption are unacceptable.

สื่อสารอย่างสุภาพ วิจารณ์งานด้วยเหตุผล เคารพความแตกต่าง และไม่เผยแพร่ข้อมูลส่วนตัวหรือข้อมูลจากกล้องของผู้อื่น

For conduct concerns, use GitHub's built-in **Report abuse** action on the relevant content or profile. For repository moderation, contact a [repository maintainer through their available GitHub profile links](https://github.com/pnntrn). Do not post private evidence in a public issue. Security vulnerabilities use the separate [private reporting channel](SECURITY.md).

Maintainers may edit or remove harmful content, close discussions, limit participation or block accounts as appropriate. These guidelines apply to this repository's issues, pull requests and other project discussions.
