# CCTV 0.4.1 maintenance proposal

Keep **CCTV** as the visible app name. Rename the repository to **pnntrn/cctv-tv**, with the description “A lightweight RTSP camera viewer for Android TV and Google TV.” Keep the existing Android package ID, signing certificate, saved profiles and Thai viewing workflow.

This is a maintenance patch using the current native Android application. It needs focused fixes and repository/release improvements; there is no architecture change.

## Scope

1. **Professional GitHub presentation:** concise README with real build/version/download badges, clear setup/development links, screenshots and honest device-verification status; repository description and topics; CHANGELOG, CONTRIBUTING, SECURITY, code of conduct, bug/feature issue forms and PR template. Add third-party notices and preserve vendored Apache notices. Apply a project license only after the owner chooses it.
2. **Build and release standards:** commit the pinned Gradle wrapper with distribution checksum; use it in CI and development instructions. Add monthly GitHub Actions dependency-update proposals. Keep CI permissions narrow. Tagged releases publish the signed APK, checksum and license/notices only after unit tests, lint, build and native TV checks pass. Verify the retained certificate and version/tag agreement before publication. Enable GitHub private vulnerability reporting and document that channel.
3. **Confirmed bug fix:** after a remembered camera is moved to another grid page, switching locations must restore that camera and its current page. A stale remembered camera ID must fall back to a valid saved page. Add regressions for both cases; preserve existing playback, draft and remote-safety tests.
4. **Version and PR:** prepare 0.4.1 with versionCode 1009, update the existing PR and release notes, and publish a signed release candidate from verified source. Keep the PR unmerged for review. The legacy updater feed remains unchanged.

## Verification

Reproduce the selection bug before the fix. Run the full unit/core/digest/updater checks, Android lint, APK builds and Android 9 TV native suite. Validate GitHub templates/workflow syntax and release checks. Inspect generated wrapper provenance/checksum and the final signed APK. Verify public release downloads, checksums and updated repository links after renaming.

Real Hikvision/Mi Box playback, hardware decoder limits and in-place update/profile preservation still require device verification. This patch does not claim those checks have passed.
