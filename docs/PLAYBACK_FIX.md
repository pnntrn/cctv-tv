# CCTV 0.3.1 compatibility pass

Target report: Mi Box MIBOX4, Android 9/API 28, 1080p, signed 0.3.0 (1006). Update checking and installation are owner-verified. Camera playback is not yet verified. Ping and unauthenticated RTSP 401 prove reachability, not valid credentials. Owner corrected substream to H.264; authenticated SDP has not been supplied.

The existing Media3 1.8.0 RTSP code requires H264 fmtp/sprop metadata before RTP. This pass vendors that same module under Apache-2.0 and uses the existing Media3 H264Reader to discover actual SPS/PPS from complete RTP NALs. There are no invented CSD bytes or production width/height defaults. The format-discovery probe accepts complete single NAL, STAP-A and FU-A parameter units and discards incomplete/oversized/sequence-broken FUs. A bounded startup RTP cache is then replayed through the existing marker-aware RTP reader; elementary-stream probe samples are never used as decoder access units. An active RTP stream that still provides no codec configuration after eight seconds ends with an actionable non-retrying SDP error. Valid SDP configuration keeps the upstream reader. Video-only track filtering occurs before constructing audio media tracks, rather than only disabling audio selection later.

H265 with missing VPS/SPS/PPS is still an unsupported-SDP condition, not an assumption about this device's codec. A native VLC/FFmpeg alternative would add a production dependency and was not introduced without authorization. The H264 repair reuses existing production dependencies. Robolectric is test-only.

Error classes retain distinct credential, channel/path, network, timeout, metadata and decoder-limit handling. No camera settings are modified. Four tiles remain the default; 9/16 are optional and do not promise hardware-decoder capacity. The permanent release key, application ID, encrypted-profile schema and updater feed remain unchanged.

Validation must include synthetic SDP/RTP parsing and decoded-frame fixtures, channels 1–11 naming/paging/identity/bulk edits, password-free draft retention, lint/release signing, and native navigation where available. Real-recorder playback must be reported separately after the owner installs the update; TV debugging is closed during implementation.
